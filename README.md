### Soldier : gestionnaire de mots de passe zero-knowledge

**FR** Gestionnaire de mots de passe open source et auto-hébergeable, pensé comme une alternative crédible aux solutions établies. Le chiffrement se fait côté client : Argon2id pour dériver les clés, AES-256-GCM pour les coffres et RSA-4096 pour le partage entre utilisateurs. Connexion par passkeys (WebAuthn), TOTP et OAuth, plus une extension Chrome (Manifest V3) publiée sur le Chrome Web Store.

**EN** Open-source, self-hostable password manager built as a credible alternative to established tools. Encryption happens client-side: Argon2id for key derivation, AES-256-GCM for vaults and RSA-4096 for sharing between users. Sign-in with passkeys (WebAuthn), TOTP and OAuth, plus a Chrome extension (Manifest V3) published on the Chrome Web Store.

### Sous-marin connecté : ESP32, iOS et MQTT

**FR** Prototype de système de contrôle d'un mini sous-marin : app iOS en SwiftUI, serveur Node.js et firmware ESP32 qui communiquent par MQTT. La migration depuis HTTP/WebSocket a fait passer la latence de 200-500 ms à 30-80 ms. Plusieurs sécurités redondantes : remontée d'urgence, limites de profondeur et arrêt automatique en cas de perte de communication.

**EN** Control-system prototype for a mini submarine: SwiftUI iOS app, Node.js server and ESP32 firmware talking over MQTT. Moving from HTTP/WebSocket to MQTT cut latency from 200-500 ms to 30-80 ms. Multiple redundant safety mechanisms: emergency surfacing, depth limits and automatic stop on lost communication.
